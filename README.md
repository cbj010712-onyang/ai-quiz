# AI·코딩 퀴즈 챌린지 · 설치 방법 (GitHub Pages + Supabase)

학생은 휴대폰으로 QR을 찍어 퀴즈를 풀고, 교실 TV에는 대시보드가 뜨고,
선생님은 관리자 페이지에서 실명 기록과 문제를 관리해요.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 학생 퀴즈 (QR로 여는 주소) |
| `dashboard.html` | 대시보드 · 휴대폰은 탭, TV(가로 1000px 이상)는 네 칸 + 참여 QR |
| `admin.html` | 관리자 · 실명 기록, 학생별 답, 기록 지우기, CSV, 문제 편집, 설정 |
| `config.js` | Supabase 주소와 키 (여기만 고치면 돼요) |
| `supabase.sql` | Supabase에 한 번 붙여 넣어 실행하는 파일 (표·함수·처음 문제 54개) |
| `js/common.js` | 세 페이지가 같이 쓰는 코드 (등급, 칭호, 업적, 순위 계산) |
| `js/mock.js` | 체험 모드 (Supabase 연결 전 예시 데이터) |
| `js/qrcode.js` | QR 만들기 (MIT 라이선스, Kazuhiko Arase) |
| `img/mascot.png` | 학교 거북이 (시작 화면·결과 이미지) |
| `img/mascot_ai.png`, `img/turtle.png` | AI 이미지 문제에 쓰는 그림 |
| `css/style.css`, `data/questions.json` | 모양, 체험용 문제 |

`config.js`가 비어 있으면 **체험 모드**로 돌아가요. 예시 학생 기록이 들어 있고,
관리자 비밀번호는 `admin1234`예요. 기록은 그 브라우저에만 저장돼요.

---

## 1. Supabase 준비 (약 10분)

1. https://supabase.com 에 로그인 → **New project** (지역은 Seoul 추천)
2. 왼쪽 **SQL Editor** → **New query** → `supabase.sql` 내용을 **전부** 붙여 넣고 **Run**
3. 다시 **New query** 에서 관리자 비밀번호를 정해요 (6글자 이상, 길수록 좋아요)
   ```sql
   select quiz__set_password('내가-정한-긴-비밀번호');
   ```
   비밀번호는 `supabase.sql` 파일 안에 적지 않아요. 그래서 이 파일은 깃허브에 올라가도 안전해요.
4. 화면 위쪽 **Connect** 버튼(또는 **Settings → API Keys**)에서 두 가지를 복사해요
   - **Project URL** (예: `https://abcdefgh.supabase.co`)
   - **Publishable key** (`sb_publishable_...`). 예전 **anon** 키(`eyJ...`)도 돼요
   - ⚠ **secret / service_role 키는 절대 쓰지 마세요.**

## 2. config.js 고치기

```js
window.QUIZ_CONFIG = {
  url: 'https://abcdefgh.supabase.co',
  key: 'sb_publishable_xxxxxxxx',
};
```

## 3. GitHub Pages에 올리기

1. **개인 계정**으로 새 저장소 만들기 (Public)
2. 이 폴더의 파일을 **폴더 구조 그대로** 올리기 (`Add file → Upload files`, 폴더째 끌어다 놓기)
3. 저장소 **Settings → Pages** → Branch: `main` / `/(root)` → Save
4. 1~2분 뒤 주소가 생겨요
   - 학생: `https://아이디.github.io/저장소이름/`
   - 대시보드: `https://아이디.github.io/저장소이름/dashboard.html`
   - 관리자: `https://아이디.github.io/저장소이름/admin.html`

포스터의 QR은 **학생 주소**로 만들어요. 관리자 페이지의 '설정' 탭에도 학생 주소 QR이 있어요.

## 4. 행사 당일 순서 (11월 25일)

1. 전날: 학생 주소에서 직접 한 판 풀어 보기 (선생님 번호는 예: 3학년 11반 40번)
2. 관리자 위쪽 빨간 **기록 초기화** → **전체** → `초기화` 라고 적고 지우기 → 연습 기록 정리
3. 관리자 상단 버튼이 **● 퀴즈 열림** 인지 확인
4. 교실 TV에서 `dashboard.html` 열기 → 큰 화면 모드 + 참여 QR이 자동으로 나와요
5. 끝나면 **● 퀴즈 닫힘** 으로 바꾸기 → 새로 시작은 막히고, 풀던 학생은 마저 풀 수 있어요
6. 관리자 → 참가 기록 → **CSV 내려받기** 로 결과 보관

> Supabase 무료 프로젝트는 일주일 동안 아무도 쓰지 않으면 잠들어요. 행사 전날 한 번 열어 두세요.

## 관리자 페이지에 들어가는 방법

| 방법 | 어떻게 |
|---|---|
| 주소로 | `https://아이디.github.io/저장소이름/admin.html` (끝의 `.html`은 빼도 열려요) |
| 숨은 입구 | 학생 화면의 학교 이름 배지, 또는 대시보드 위쪽 학교 이름 배지를 **2초 안에 5번** 누르기 |
| 휴대폰 QR | 관리자 → 설정 → **관리자 주소 QR**을 휴대폰 카메라로 찍기 |
| 로그인 유지 | 로그인할 때 **이 기기에서 로그인 유지**를 켜면 창을 닫아도 다시 안 물어봐요 (개인 기기에서만) |

어느 길로 와도 관리자 비밀번호가 있어야 들어갈 수 있어요.

## 기록 초기화

관리자 위쪽 빨간 **기록 초기화** 버튼 (설정 탭에도 있어요)

- **전체 / 한 학년 / 한 반** 중에서 골라요. 지워질 학생 수가 미리 보여요.
- `초기화` 라고 적어야 지우기 버튼이 켜져요. 지운 기록은 되돌릴 수 없어요.
- 지우기 전에 **전체 기록 CSV로 받기**로 백업할 수 있어요.
- 문제와 설정, 비밀번호는 그대로예요. 대시보드 순위와 칭호는 남은 기록으로 다시 계산돼요.
- 학생 한 명만 지우려면 참가 기록 표의 **지우기**를 써요.

## 5. 문제 바꾸기 · 추가하기

- 관리자 → **문제** 탭 → `수정` 또는 `+ 새 문제`
- 풀이 방식 12가지: O/X, 4지선다, 모두 고르기, 직접 입력, 빈칸 채우기, 블록 쌓기, 짝 맞추기, 찾아내기,
  분류하기, AI 판별(그림 O/X), 찾아 누르기(그림에서 수상한 곳), 사진 고르기(그림 두 장)
- 한 판에 스테이지마다 ★3 · ★★1 · ★★★1개를 뽑아요. 정보윤리에는 그림 문제가 하나씩 꼭 들어가요.
  문제가 모자라면 관리자 화면에 빨간 안내가 떠요.
- **그림 문제**: 저장소의 `img` 폴더에 그림을 올리고 주소를 `img/파일이름.png` 처럼 적어요.
  '찾아 누르기'는 편집 창의 그림 위에서 끌어서 정답 네모를 그리면 돼요.
- `출제` 스위치를 끄면 문제를 지우지 않고 잠깐 뺄 수 있어요.

## 6. 이렇게 안전하게 만들었어요

- 정답·힌트·해설은 서버에만 있어요. 학생 화면에는 답한 뒤에만 정답이 와요.
- 채점과 시간 재기도 서버가 해요 (60초 + 인터넷 지연 3초 여유). 같은 문제는 한 번만 제출돼요.
- 학생 브라우저는 표를 직접 읽거나 쓸 수 없고, 정해진 함수만 부를 수 있어요.
- 대시보드 이름은 가운데 글자가 가려져요 (예: 박*훈). 실명은 관리자만 봐요.
- 첫 도전만 기록돼요. 새로고침하거나 다시 들어와도 하던 곳부터 이어서 해요.
- 관리자 비밀번호가 틀리면 1초씩 늦게 답해서 마구 넣어 보기를 어렵게 해요.
- 대시보드는 바뀐 게 있을 때만 새 데이터를 받아요 (TV 5초, 휴대폰 10초마다 확인).

## 7. 설정에서 바꿀 수 있는 것

- 학교 이름, 퀴즈 이름, 퀴즈 열기/닫기, 문제당 제한 시간(20~180초)
- **등급 방식**: 맞힌 개수 / 전체 순위 / 개수 + 순위(처음 값)
- 관리자 비밀번호

## 8. 이럴 땐

| 보이는 글 | 할 일 |
|---|---|
| 서버 함수를 찾을 수 없어요 | `supabase.sql`을 끝까지 실행했는지 확인, 1분 뒤 새로고침 |
| 관리자 비밀번호가 아직 없어요 | 1-3단계의 `quiz__set_password` 한 줄 실행 |
| 이 번호는 다른 이름으로 이미 참여했어요 | 학생이 번호를 잘못 골랐을 때 → 관리자에서 그 기록 `지우기` |
| 지금은 퀴즈 시간이 아니에요 | 관리자 상단 버튼으로 퀴즈 열기 |
| 화면이 체험 모드로 나와요 | `config.js`의 url, key 확인 |

`supabase.sql`은 다시 실행해도 괜찮아요. 참가 기록과 문제, 비밀번호는 그대로 남아요.
